## Виконав
**Боденчук Олександр** — студент

## Опис
Мобільний Android-додаток для голосування та рейтингування, розроблений у рамках лабораторної роботи №2.

Додаток дозволяє:
- Додавати варіанти для голосування
- Голосувати за обрані варіанти
- Переглядати рейтинг у реальному часі (лідерборд)

## Технології
- **Мова:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Архітектура:** MVVM (ViewModel + StateFlow)
- **Мінімальна версія Android:** API 24 (Android 7.0)

## Структура проєкту
```
app/src/main/java/com/example/votingapp/
├── MainActivity.kt              — головна активність
├── model/
│   └── VoteOption.kt            — модель даних варіанту голосування
├── ui/
│   ├── VoteCard.kt              — UI-компонент картки голосування
│   ├── VoteScreen.kt            — головний екран додатку
│   └── theme/
│       ├── Color.kt             — кольорова палітра
│       └── Theme.kt             — тема додатку
└── viewmodel/
    └── VoteViewModel.kt         — логіка та стан додатку
```

## Збірка та запуск
1. Відкрити проєкт у Android Studio
2. Синхронізувати Gradle
3. Запустити на емуляторі або фізичному пристрої
